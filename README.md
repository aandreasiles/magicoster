## ✨ Características y Experiencia Mágica

- **🃏 Escena 3D Hero Interactiva (Three.js + R3F + Drei)**:
  - Carta 3D flotante con inclinación reactiva al cursor (Raytracing sutil, brillo dorado, símbolos grabados).
  - Efecto interactivo al hacer clic con giro 3D completo.
  - Anillos rúnicos celestiales orbitando y partículas de polvo de estrellas en tiempo real.
- **🔮 Experiencia Interactiva de Mentalismo en Vivo**:
  - Test mental donde el usuario elige una carta mentalmente.
  - Animación de extracción de ondas psíquicas y lectura mental.
  - Efecto de desvanecimiento imposible de la carta elegida con confeti dorado.
- **🎭 Sección "El Rey de Trébol" en Sala Houdini de Madrid**:
  - Información completa del espectáculo en el teatro de magia más grande de Europa.
  - Horarios semanales, aforo íntimo para 25 espectadores, localización y enlace directo a Atrápalo (+1.030 reseñas con 4.9★).
- **💼 Catálogo de Servicios Mágicos**:
  - **Empresas & Galas**: Presentador y maestro de ceremonias, magia de marca infiltrada, conferencias.
  - **Bodas & Particulares**: Magia de cóctel itinerante rompehielos, dinamización de banquete y personalizaciones exclusivas.
  - **Coctelerías & Ocio**: Magia de cerca en mesas y barra para fidelización de clientes.
  - **Especialidades**: Mentalismo, Magia Tecnológica (Smartphones) y Pickpocket Cómico.
- **🎬 Videoteca en Directo**:
  - Actuaciones reales en Netflix España, bodas con 300 invitados, coctelerías y trailer de Sala Houdini con reproductor modal optimizado.
- **📸 Galería Fotográfica de Escena**:
  - Fotografías de alta resolución con vista ampliada (lightbox).
- **⭐ Opiniones Verificadas & Celebridades**:
  - Testimonio destacado de **Jorge Fernández** (*La Ruleta de la Suerte*), junto a reseñas reales de empresas y particulares.
- **📜 Sobre Pablo Costas**:
  - Trayectoria (+15 años), cliente corporativo (Cartier, Rolex, Netflix, BMW, Microsoft, etc.), bilingüe (Español & Inglés) y equipo del festival *León Vive la Magia*.
- **📱 Formulario de Reserva Interactivo & Canales Directos**:
  - Selector de evento, formulario reactivo con respuesta visual y enlace directo a WhatsApp y llamada telefónica.
- **✨ Efectos Atmosféricos y Fluidez**:

## 🛠️ Stack Tecnológico

- **React 19 + TypeScript + Vite**
- **Three.js** (`three`, `@react-three/fiber`, `@react-three/drei`)
- **GSAP** & `@gsap/react`
- **Framer Motion** (`framer-motion`)
- **Lenis Smooth Scroll** (`lenis`)
- **Tailwind CSS**
- **Lucide Icons**
- **Canvas Confetti**

## 🚀 Despliegue & Ejecución Local

### Instalación de dependencias:
```bash
npm install
```

### Modo desarrollo:
```bash
npm run dev
```

### Compilación para producción:
```bash
npm run build
```
